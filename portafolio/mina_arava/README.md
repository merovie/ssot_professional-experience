# ⛏️ Macro Activo: Mina Arava (Israel)

## 📝 Contexto General
Proyectos ejecutados durante la fase de construcción y desarrollo de la operación Timna (Arava Mines). El enfoque principal fue la transición de datos de exploración hacia un modelo operativo de recursos y la gestión técnica de riesgos geotécnicos e hídricos.

| Proyecto | Descripción Clave | Dominio Principal |

| **Estimación de Recursos** | Actualización de modelo de bloques mediante Kriging. | `#EstimacionRecursos` |
| **Pozos Hídricos** | Supervisión de perforación y control de línea base. | `#QAQC` |

* **Metodología:** Mapeo por celdas, Kriging Ordinario.
