# 📂 Portafolio de Proyectos y Evidencias

Este directorio contiene la documentación detallada de las intervenciones técnicas y estratégicas realizadas a lo largo de mi carrera. Cada proyecto está documentado bajo la metodología **S-T-A-R** (Situación, Tarea, Acción, Resultado).

## 🧭 Estructura del Portafolio

Los proyectos están agrupados por **Macro-Asociados** (Activos mineros, Software o Líneas de consultoría):

### ⛏️ Operaciones Mineras
*   **[Mina Arava (Israel)](./mina_arava/)**: Proyectos de geología de mina, modelamiento de recursos y control hídrico en cobre.
*   **[Proyectos Geoinnova](./s-geognosim/)**: Desarrollo de productos Deep-Tech y estrategia de negocios para minería.
*   **[Consultoría Estratégica](./consultoria/)**: Clasificación de recursos y evaluaciones técnicas.

### 💻 Soluciones Digitales e Innovación
*   **[Ecosistema Isatis.neo](./s-isatis/)**: Gestión de cuentas y entrenamiento especializado.
*   **[Software Stocks](./s-stocks/)**: Desarrollo de MVP y financiamiento Cloud.
*   **[Ley I+D](./leyid/)**: Arquitectura de proyectos para beneficios tributarios.

## 📊 Cómo leer los proyectos
Cada archivo de proyecto contiene metadatos en la parte superior que lo vinculan con el resto del SSoT:

*   **ID**: Identificador único del proyecto.
*   **Verticales**: El eje estratégico (V1-V4).
*   **Dominios**: Las competencias técnicas aplicadas (ej: `#QAQC`, `#IDi`).

> [!TIP]
> Puedes buscar proyectos por dominio usando el buscador de GitHub (ej: `path:portafolio #EstimacionRecursos`)
